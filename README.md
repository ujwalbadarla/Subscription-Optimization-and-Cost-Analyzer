# Subscription-Optimization-and-Cost-Analyzer
A full-stack MERN web application that helps users efficiently manage, monitor, and optimize their subscription-based services in one centralized platform.

Users can track recurring expenses, receive renewal reminders, analyze spending habits, and reduce unnecessary subscription costs.

⸻

🌟 Features

* 🔐 User Authentication (Signup/Login)
* 📋 Add, Edit, and Delete Subscriptions
* ⏰ Renewal Reminder Tracking
* 💰 Monthly & Yearly Expense Analysis
* 📊 Dashboard Analytics
* 🗂️ Subscription Categorization
* 📱 Responsive UI Design
* 🔒 Secure Data Management

⸻

⚙️ Installation & Setup

Clone Repository
git clone https://github.com/ujwalbadarla/Subscription-Optimization-and-Cost-Analyzer.git

Frontend Setup
cd client
npm install
npm run dev

Backend Setup
cd server
npm install
npm start

🗄️ MongoDB Setup
MONGO_URI=your_mongodb_connection_string
PORT=5000
